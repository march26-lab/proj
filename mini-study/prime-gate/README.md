## 素数関門研究の実験プログラム

Zennブック「[素数の関門をたどる ー GGTレス素数から始まるミニ研究](https://zenn.dev/march26/books/33c3e7923f6999)」の数値実験に用いたPythonコードを公開しています。

pythonのバージョン: 3.10.0。
以下のコマンドは、各 `.py` ファイルを保存したフォルダをカレントディレクトリとして実行してください。

本コードは数学的な構成と処理の対応をわかりやすく示すことを優先しており、実行速度の最適化は行っていません。大規模な計算には適していません。


### list_ggt_less.py: GGTレス素数のリストアップ

100万以下のGGTレス素数をリストアップし、同じディレクトリの `ggt_less.txt` に保存します。

#### 実行方法

```
python list_ggt_less.py
```

main()関数の冒頭 `Q_MAX = 1000000` を書き換えることで、リストアップする上限を変えられます。


### make_chart_data.py: 関門チャートの基礎データ作成

関門チャート図を作成するための基礎データを作成し、同じディレクトリの `chart_data.json` に保存します。

#### 実行方法

```
python make_chart_data.py
```

main()関数の冒頭

```
P_VIEW_MIN, P_VIEW_MAX = 11, 240
D_VIEW_MIN, D_VIEW_MAX = 6, 110
```

を書き換えることで、基礎データとして保存する関門 $p$ と差分 $d$ の範囲を調整できます。内部の計算は、指定した下限にかかわらず $p=11$ から行います。


### draw_chart.py: 関門チャートの表示

上記で作成したファイル `chart_data.json` を読み込み、関門チャートを描画します。

実行には `matplotlib` が必要です。実験時に用いたバージョン: 3.10.9。

#### 実行方法

```
python draw_chart.py
```

main()関数の冒頭

```
P_VIEW_MIN = 11
D_VIEW_MIN = 6
D_VIEW_MAX = 110
```

を書き換えることで、表示される関門 $p$ と差分 $d$ の範囲を調整できます。
関門 $p$ は下限だけ変更でき、上限は読み込むファイルの内容で決まります。

ファイル内容に整合しない範囲を指定すると、正しく表示されません。


### watch_early_cap.py: 初期CAP構築の追跡

初期CAPが構築されていく様子を表示します。

#### 実行方法

```
python watch_early_cap.py
```

図の下にある `prev` / `next` ボタンで $q \mod{30} = 11,17,29$ のチャートが切り替わります。 

main()関数の冒頭 `CYCLE_MAX = 10` は、法30を周期として何サイクル目までを追跡するかのパラメータです。
初期CAP構築の様子を眺めるという目的においては、あまり大きな値に変えてもメリットはありません。
