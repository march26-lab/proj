## ゴールドバッハの星座図のサンプルプログラム

Zenn記事「[ゴールドバッハの星座図 ― 素数ペアを天体観測する](https://zenn.dev/march26/articles/f625d63cb657e8)」に掲載したPythonコードを公開しています。

以下のコマンドは、各 `.py` ファイルを保存したフォルダをカレントディレクトリとして実行してください。

実行には `matplotlib` が必要です。

動作確認環境: `python3.10.0, matplotlib 3.10.9`。


### goldbach_comet.py: ゴールドバッハの彗星の描画

ゴールドバッハ彗星…横軸に偶数 $n$、縦軸に和が $n$ となる素数ペアの数 $G(n)$ をプロットした図です。

また、大まかな見積もり値を点線で示します。

#### 実行方法

```
python goldbach_comet.py
```

main()関数の冒頭 `n_max = 10000` を書き換えることで、横軸の上限を変えられます。


### goldbach_star_atlas.py: ゴールドバッハの星座図の描画

ゴールドバッハ星座図…横軸に偶数 $n$、縦軸に和が $n$ となる素数ペア $p,q (p\le q)$ の差 $d=q-p$ をプロットした図です。

#### 実行方法

```
python goldbach_star_atlas.py
```

main()関数の冒頭 `n_max = 1000` を書き換えることで、横軸の上限を変えられます。

あまり大きな値を指定すると、点同士が密集しすぎてベタ塗りのようになってしまいます。
